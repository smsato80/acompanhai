# Sistema visual

## Direção recomendada

O produto deve transmitir simplicidade, confiança e acompanhamento. As páginas estratégicas exploraram três direções: Dashboard energético, Dark Moderno e Premium Sofisticado. A escolha final deve ser feita antes da implementação da interface.

## Regras comuns

- Mobile-first.
- Português claro.
- Contraste mínimo de 4,5:1 para texto normal.
- Sem emoji ou caracteres tipográficos como ícones de interface.
- Ícones SVG compartilhados e consistentes.
- Cores via tokens semânticos, não literais espalhados.
- Estados de erro, vazio, sucesso e carregamento definidos.

## Cliente em treino/atividade

- Ação principal visível.
- Poucos toques.
- Botões grandes.
- Uma atividade por vez quando isso reduzir confusão.
- Feedback imediato depois de salvar.

## Profissional

- Priorizar clientes que precisam de atenção.
- Evitar dashboard decorativo sem ação.
- Mostrar motivo de cada alerta.
- Usar tabelas apenas quando forem melhores que cards no desktop.

## Temas

Os temas Dark Moderno e Premium Sofisticado são referências de marca/marketing. O produto operacional deve escolher um tema principal e manter tokens consistentes para não duplicar manutenção.
